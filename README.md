## 🎨 Enfoque del proyecto

El objetivo del proyecto fue desarrollar un portafolio que funcione no solo como una presentación personal, sino también como una **herramienta comercial para ofrecer servicios de desarrollo web**.

Se priorizaron:

* Una navegación sencilla e intuitiva.
* Diseño responsive.
* Experiencia de usuario.
* Buen rendimiento.
* Presentación clara de los servicios.
* Animaciones y transiciones sutiles.
* Diseño moderno y profesional.
* Facilidad de contacto para potenciales clientes.
